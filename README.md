# Smart Hostel Outpass & Home Leave System

## Project Description
A Python-based application that digitizes hostel outpass and home leave requests.

## Features
- Student registration and login
- Outpass and home leave applications
- Warden approval and rejection
- Gate pass code verification
- Student check-in and check-out tracking
- Overdue and late-return monitoring

## Technologies Used
- Python
- SQLite
- GitHub
